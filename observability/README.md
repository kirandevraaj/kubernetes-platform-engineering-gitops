# Observability (local lab)

GitOps-managed Prometheus and Grafana for `platform-lab` on the VMware cluster.

## Architecture

```text
Browser / LAN
     |
     |  MetalLB VIP (Grafana LoadBalancer; not 192.168.56.200)
     v
 Grafana (monitoring)
     ^
     |  queries
     |
 Prometheus (ClusterIP, monitoring)
     ^
     |  ServiceMonitor scrape /metrics
     |
 platform-lab pods (ClusterIP :8000)
     ^
     |  Host platform-lab.local
     |
 ingress-nginx (MetalLB VIP 192.168.56.200)
```

| Component | Role | Exposure |
|---|---|---|
| Prometheus | Scrapes `platform-lab` `/metrics` via ServiceMonitor; scrapes cluster metrics | ClusterIP only |
| Grafana | Dashboards over Prometheus | LoadBalancer (MetalLB `lab-pool`) |
| ServiceMonitor | Declares scrape of Service `platform-lab` port `http` path `/metrics` | In `platform-lab` ns (local overlay) |

Prometheus and Grafana are **not** installed under the `platform-lab-local` Application. They are owned by Application `platform-lab-observability`.

## Git layout

| Path | Contents |
|---|---|
| `observability/values-kube-prometheus-stack.yaml` | Helm values (Grafana LoadBalancer, Prometheus ClusterIP, retention, PVC) |
| `observability/dashboards/` | Grafana dashboard ConfigMap (`grafana_dashboard=1`) |
| `gitops/projects/platform-lab-observability.yaml` | AppProject |
| `gitops/applications/platform-lab-observability.yaml` | Multi-source Application (Helm + values + dashboards) |
| `kubernetes/overlays/local/servicemonitor.yaml` | Application ServiceMonitor |
| `kubernetes/overlays/local/networkpolicy-prometheus-patch.yaml` | Allow scrapes from namespace `monitoring` |

AWS overlay is unchanged.

## Apply GitOps objects

```powershell
kubectl config current-context   # must be ckad-lab
kubectl --context=ckad-lab apply -f gitops/projects/platform-lab-observability.yaml
kubectl --context=ckad-lab apply -f gitops/applications/platform-lab-observability.yaml
```

Discover Grafana EXTERNAL-IP after sync (do not assume `.201`):

```powershell
kubectl --context=ckad-lab get svc -n monitoring -l app.kubernetes.io/name=grafana
```

Admin password (generated by the chart):

```powershell
kubectl --context=ckad-lab get secret -n monitoring kube-prometheus-stack-grafana -o jsonpath="{.data.admin-password}"
# then base64-decode the value
```

## Validation

```powershell
kubectl --context=ckad-lab get application -n argocd platform-lab-observability
kubectl --context=ckad-lab get pods,svc -n monitoring
kubectl --context=ckad-lab get servicemonitor -n platform-lab
kubectl --context=ckad-lab get endpoints -n platform-lab platform-lab
```
