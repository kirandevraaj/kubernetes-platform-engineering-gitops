# LinkedIn Featured — Project 1

**Title:** Kubernetes Platform Engineering & GitOps Lab

**Short description:**  
Portfolio lab building a dual-environment Kubernetes platform (VMware kubeadm + AWS EKS) with Terraform, Jenkins CI, Argo CD GitOps, immutable image digests, Prometheus/Grafana, security hardening, resilience experiments, EBS storage/snapshots, DR measurements, and Python/Ansible automation.

**Implemented (lab-verified):** multi-env GitOps, digest promotion, HPA/PDB, failure drills, ingress HA, EBS persistence & node recovery, RBAC/PSA, ops runbooks.

**Not claimed:** production deployment, enterprise production ownership, customer workloads, commercial SLAs, multi-region DR, AWS Backup EKS restore execution.

**Stack:** Kubernetes, Terraform, Jenkins, Docker, Argo CD, Kustomize, Prometheus, Grafana, EBS CSI, Python, Ansible, AWS.
