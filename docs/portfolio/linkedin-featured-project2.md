# LinkedIn Featured — Project 2

**Title:** Infrastructure Automation with Terraform, Ansible & Python

**Short description:**  
Automation layer for the platform lab: Terraform for AWS infrastructure lifecycle; Python CLI (`platform-automate`) with Kubernetes client and Boto3 concepts; Ansible for operational orchestration via Linux/Jenkins (Ansible Runner patterns, idempotency, check/diff).

**Limitation (explicit):** Windows Ansible CLI is blocked in this project — Linux/Jenkins is the supported execution environment. Live Boto3 on the Windows workstation path is partial.
