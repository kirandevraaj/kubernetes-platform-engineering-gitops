# Tool boundaries

| Tool | Role |
|---|---|
| Git | Desired state |
| Jenkins | CI |
| Docker | Artifact build/publish |
| Terraform | Infrastructure lifecycle |
| Python | Custom automation logic |
| Boto3 | AWS API |
| Kubernetes client | Kubernetes API |
| Ansible | Operational configuration/orchestration |
| Argo CD | GitOps reconciliation |
| Prometheus | Metrics collection/query |
| Grafana | Visualization |
| kube-state-metrics | Kubernetes object-state metrics |
| node-exporter | Node metrics |
| Metrics Server | Resource metrics for Kubernetes APIs / HPA |

These tools are complementary, not substitutes.
