# Disaster Scenario Matrix (Project 1 — Section 25)

**Purpose:** Classify common failure scenarios for the VMware and AWS labs, recovery sources, and honest test status.  
**Environments:** `ckad-lab` (Kubernetes 1.31.14) · `platform-lab-aws` / `platform-lab-aws-lab-eks` (1.36.4, `ap-south-1`)  
**Policy:** **Tested?** reflects evidence in this repo only. Measured Section 25 drills are recorded in [`dr-lab-evidence.md`](./dr-lab-evidence.md).  
**Safety:** Do not destroy main EKS/VPC, `platform-lab*`, `storage-lab`, `security-lab`, observability, or EBS `vol-05faa26874d720ecd`. Disposable namespaces: `dr-lab`, `dr-storage-restore`.

## Summary

Most **Tested** evidence in Project 1 today is **HA/self-healing** (pods, nodes within AZ, ingress HA), not full **DR** (cluster loss, region loss, snapshot restore). Section 25 adds disposable drills (`dr-lab`, `dr-storage-restore`) to measure Git/Argo/namespace/snapshot recovery without touching production-like workloads.
